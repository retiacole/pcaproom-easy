# pcaproom-easy v0.1.0

パケットを開き、詳細を読み、根拠を選んで答えるネットワーク入門教材です。Wireshark風の画面で、基本プロトコルを45問・83設問で練習します。

## はじめ方

1. [pcaproom-easy.html](https://github.com/retiacole/pcaproom-easy/blob/main/pcaproom-easy.html) を開き、右上の「Download raw file」で保存して、ブラウザで開きます。リポジトリの「Code → Download ZIP」で全体を保存・展開しても使えます。
2. 「最初のパケットを開く」から始めます。学習マップのどの章からでも選べます。
3. パケット一覧のNo.を押して詳細を開き、必要な項目を選びます。
4. 「根拠に追加」を押し、回答と一緒に答え合わせします。
5. 複数設問がある問題は、すべて正解すると1フラグです。

プレイ時のインストール・サーバー・アカウント・インターネット接続は不要です。JavaScriptとdialog要素に対応したブラウザが必要です。

## 内容

| 区分 | 内容 | 問題数 |
| --- | --- | --- |
| 操作 | 一覧・詳細・根拠選択、表示フィルター | 6 |
| 基礎プロトコル | Ethernet、ARP、IPv4/IPv6、ICMP、ICMPv6/NDP、UDP | 18 |
| 通信を読む | TCP、DNS、DHCPv4、NTP、HTTP、TLS | 18 |
| 卒業調査 | 端末の接続、通信できない理由、Webアクセスと観測限界 | 3 |

各章3問、15章で45問です。12のプロトコルテーマと操作2章、卒業調査1章を含みます。ガイド付き→練習→自力で確認と進みます。IPv6のRA、DHCPv6/SLAAC、QUIC/HTTP/3などは用語帳にも補足しています。DHCPv6やQUICそのもののパケット問題は初版に含みません。

全問に3段階ヒントと答え・解説があります。1問100ポイント、合計45フラグ・4500ポイントです。時間制限、誤答やヒントによる減点はありません。解説を見ただけではクリアせず、実際に回答と根拠をそろえる必要があります。復習で回答を書き換えても、正答時の記録を保存して獲得済みフラグを保ちます。

## 画面の機能

- パケット一覧とプロトコル別詳細。基本項目表示と全項目表示を切り替えられます。
- フィールドを選ぶと、対応する16進数バイトを強調します。解析で生成・再構成したフィールドには、その旨を表示します。
- 表示フィルター、対応構文の早見表、元の表示への解除。
- TCPストリームの追跡。方向ごとにシーケンス順で再構成し、再送を重複させません。
- 回答、根拠選択、複数パケット選択、順序指定、フィルター問題。
- 同じ教材を本物のWiresharkで確認できるPCAP保存。
- 用語帳、ヒント・解説、進捗保存・読込。

### フィルターの範囲

プロトコル・フィールドの存在、`==`、`!=`、`>`、`<`、`>=`、`<=`、`contains`、`&&`/`and`、`||`/`or`、`!`/`not`、かっこに対応します。代表例は `dns`、`udp`、`ip.addr == 10.0.0.10`、`tcp.flags.syn == 1` です。

Wiresharkの全フィルター機能を再実装したものではありません。正規表現、集合、CIDR、関数、フィールド同士の比較などは未対応です。不正な構文はエラーを表示し、直前の適用済み表示を保持します。フィルター問題は適用結果で採点し、意味が同じ条件式を受け付けます。

## 保存と復元

自動保存キーは `pcaproom-easy.progress.v1` です。ほかのroomの保存領域は読み書きしません。配布場所やファイルの保存場所、ブラウザが変わると保存領域が別になる場合があります。移行には進捗JSONを使ってください。

ローカルHTMLでの自動保存はブラウザによって扱いが異なります。保存できない場合は画面に案内します。「保存」でJSONを残しておけば、HTMLの移動やブラウザ変更後も「読込」で復元できます。読込では変更内容を確認し、現在の進捗をバックアップしてから置き換えます。確認でキャンセルした場合や、ファイルが不正な場合は現在の進捗を変更しません。

## 教材データと観測範囲

41個の合成PCAP、240フレームを同梱します。すべて架空のアドレス・名前・通信内容です。実際の端末操作、ネットワーク通信、ライブキャプチャは行いません。任意PCAPの読込機能はありません。

ビルド時に実PCAPバイトを生成し、tsharkで解析したフィールド・表示・位置をHTMLに埋め込みます。プレイ時にtsharkは必要ありません。教材とPCAPの対応を維持するため、表示用の値を手作業で別に作る方式ではありません。

TLSは構造を読むための合成データです。特に不透明なApplication Dataは実セッションの暗号文を再現したものではなく、その点を教材内に明記しています。SNIが常に見えるとは扱いません。DNS応答、ping成功、HTTP応答コードだけで接続成功・サービス正常・攻撃を断定しない問題を含みます。

## ソースからのビルド

開発時に必要なもの：Node.js 22以上、Python 3（標準ライブラリのみ）、tshark。検証したtsharkは4.6.7です。

```sh
npm run build
```

既定の実行ファイルはPython `/usr/bin/python3`、tshark `/usr/local/bin/tshark` です。異なる環境では `PCAPROOM_PYTHON` と `PCAPROOM_TSHARK` に実行ファイルのパスを指定してください。Wiresharkのユーザー設定・TLS鍵設定は読み込まず、一時プロファイルで解析します。

- `content/`：教材・問題・正答・パケット仕様
- `packet-tools.js`：実PCAP生成・TCP再構成
- `decode-pcap.py`：tsharkのPDMLからフィールド抽出
- `src/engine.js`：表示フィルター・採点・進捗検証
- `src/app.js` / `src/style.css` / `src/shell.html`：画面
- `src/data.js` / `captures/` / `pcaproom-easy.html`：ビルド結果
- `tests/`：パケット・採点・DOM操作のテスト

## 検証

```sh
npm install
npm test
```

テスト時だけjsdomを使います。プレイ用HTMLには外部パッケージを読み込む処理はありません。既存のjsdomを使う場合は `PCAPROOM_JSDOM_MODULE` でモジュールのパスを指定できます。`PCAPROOM_HTML` にHTMLのパスを指定すると、DOMテストはその配布ファイル自体を検証します。

25件の自動テストで、パケット生成・チェックサム、フィルター、全45問・83設問の画面操作、正答・誤答・根拠、全フラグ獲得、保存・再開、読込確認、PCAP出力、ストリーム再構成を検証しています。

実ブラウザでローカルHTMLを開く表示確認は、実行環境のURL制限により未実施です。DOMテストでは表示レイアウト・実ファイルURLでの保存動作・実際のダウンロードUIは検証していません。
